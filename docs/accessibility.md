# Έλεγχος προσβασιμότητας · 21 Νοεμβρίου 2026

Δοκιμάσαμε το λειτουργικό πρωτότυπο σε Chromium με axe-core 4.14.1. Το τηλέφωνο είχε επιφάνεια 412 × 915 και η σκηνή 1600 × 900. Τρέξαμε όλους τους αυτοματοποιημένους κανόνες με ετικέτες WCAG 2.0, 2.1 και 2.2 επιπέδου A ή AA, σε ολόκληρο το έγγραφο κάθε κατάστασης. Οι διάλογοι άνοιξαν με τα χειριστήρια της εφαρμογής. Για την άφιξη, το εμπόδιο και το κουπόνι χρησιμοποιήσαμε δοκιμαστικές εγγραφές μέσω του API.

## Αποτελέσματα

Οι στήλες μετρούν παραβάσεις **ανά κανόνα και κατάσταση**. Ο ίδιος κανόνας μπορεί να αφορά περισσότερα στοιχεία. Σε όλες τις μετρήσεις οι κρίσιμες, μέτριες και μικρές παραβάσεις ήταν μηδέν.

| Οθόνη | Καταστάσεις | Σοβαρές πριν | Σοβαρές μετά |
|---|---|---:|---:|
| Αρχική, Σχετικά, Αποστολές, Σήματα συσκευής | Αρχική κατάσταση κάθε οθόνης | 0 | 0 |
| Βοήθεια πεζού και εθελοντή | Έναρξη αιτήματος και κατάλογος αιτημάτων | 0 | 0 |
| Σάρωση | Αρχική κατάσταση | 0 | 0 |
| Τηλέφωνο | Ερώτηση προορισμού, εύρεση, περπάτημα | 0 | 0 |
| Εσωτερική διαδρομή | Πριν, κατά την προσομοίωση, μετά την καταγραφή | 0 | 0 |
| Παιχνίδι | Χάρτης, μενού, άλμπουμ, προνόμια, «Κοντά σας», κάρτα αποστολής, κάμερα, επιστροφή στην κάρτα | 0 | 0 |
| Παιχνίδι | Ξεκλείδωμα κουπονιού μετά από τρεις απαντήσεις | — | 0 |
| Σκηνή | Σύγκριση, εναρκτήρια φράση, καρτέλα άφιξης | 0 | 0 |
| Σκηνή | Πηγές | 1 | 0 |
| Σκηνή | Περπάτημα | 1 | 0 |
| Σκηνή | Σκοτεινή στιγμή | 2 | 0 |
| Σκηνή | Κλείσιμο | 1 | 0 |

Το κουπόνι προστέθηκε στην επαναληπτική μέτρηση. Τα μηδενικά αφορούν όσα μπορεί να εντοπίσει το εργαλείο στις συγκεκριμένες καταστάσεις.

- Στους δείκτες του χάρτη η βιβλιοθήκη έδινε γενικό όνομα εικόνας πάνω από το πραγματικό όνομα του προορισμού ή του εμποδίου. Το περίβλημα αφήνει πλέον το περιεχόμενό του να δώσει το όνομα. Κανόνας `label-content-name-mismatch`.
- Στη σκοτεινή στιγμή υπήρχε κείμενο με αντίθεση 1,89:1. Σκοτεινιάζει πλέον μόνο το χαρτογραφικό υπόβαθρο. Οι ετικέτες του χάρτη αποσύρονται όσο μιλά η φωνή, ενώ η λεζάντα και η ένδειξη επίδειξης κρατούν την αντίθεσή τους. Κανόνας `color-contrast`.

## Έλεγχοι πέρα από το axe

Διασχίσαμε με Tab τα ενεργά χειριστήρια του τηλεφώνου στις τρεις επιλογές προφίλ, στην ερώτηση, στην επιβεβαίωση και στο περπάτημα. Στο παιχνίδι διασχίσαμε χάρτη, μενού, άλμπουμ, προνόμια, λίστα κοντινών αποστολών, κάρτα και κάμερα. Ελέγξαμε ότι τα ενεργά στοιχεία είχαν ορατό περίγραμμα και ενεργοποιήσαμε με Enter τη διαδρομή από τη λίστα στην αποστολή, στην κάμερα και πίσω. Η λίστα παρέχει εναλλακτική στα απευθείας πατήματα πάνω στον χάρτη. Στη σκηνή δοκιμάσαμε το σενάριο με τα πλήκτρα του παρουσιαστή, μαζί με τη σύγκριση και τις πηγές.

Στο παιχνίδι, οι απαντήσεις έχουν κείμενο και σύμβολο. Η επιβεβαίωση δίνει λεκτική σφραγίδα. Η παλιά πορεία στη σκηνή είναι διακεκομμένη και η αλλαγή έχει λεζάντα. Με μειωμένη κίνηση η σφραγίδα εμφανίζεται χωρίς τη μεγέθυνση και η διαδρομή σχεδιάζεται αμέσως. Η σκοτεινή στιγμή και οι οδηγίες παραμένουν διαθέσιμες.

Για το 200% ελέγξαμε τη διάταξη σε πλάτος 206 CSS pixels, ισοδύναμο με τη μισή επιφάνεια ενός τηλεφώνου 412 pixels. Αρχικά υπερχείλιζαν οι σελίδες «Σχετικά», αποστολών, σημάτων συσκευής, εσωτερικής διαδρομής και σάρωσης. Μετά τις αλλαγές αναδίπλωσης, δέκα αρχικές οθόνες χωρούσαν χωρίς οριζόντια κύλιση του εγγράφου. Στο ίδιο πλάτος ελέγξαμε επιπλέον με Tab τα χειριστήρια σε τέσσερις καταστάσεις του τηλεφώνου και επτά του παιχνιδιού. Οι διάλογοι χωρούσαν επίσης στα 206 pixels.

Εκκρεμούν δοκιμές με τυφλό άτομο και άλλα άτομα με αναπηρία, πραγματικό TalkBack ή VoiceOver, μεγεθυντή σε συσκευή, κλήση δύο χρηστών και επιτόπια πλοήγηση. Τα αποτελέσματα δεν συνιστούν πιστοποίηση WCAG.

## Επανάληψη

Από τη ρίζα, με διαθέσιμο web και δικό σας δοκιμαστικό API με ενεργά demo endpoints και κλειδί sandbox:

```sh
scripts/a11y http://localhost:5173
scripts/record-backup http://localhost:5173
```

Τρέξτε τις εντολές διαδοχικά. Προτιμήστε φρέσκια διεργασία API για κάθε πρόβα, ώστε να υπάρχουν διαθέσιμες αποστολές. Οι δοκιμαστικές απαντήσεις μένουν στη μνήμη του server. Τα scripts κλείνουν τις αναφορές εμποδίου που δημιουργούν. Το πρώτο script εμφανίζει αποτελέσματα ανά οθόνη και αποτυγχάνει σε σοβαρή ή κρίσιμη παράβαση ή αν δεν άνοιξε μια απαιτούμενη κατάσταση. Με `ION_AXE_REPORT=/tmp/ion-a11y.json` γράφει και τα στοιχεία που βρήκε. Το καθημερινό `scripts/check` παραμένει ανεξάρτητο.

Χρησιμοποιούνται το εγκατεστημένο Playwright με το αντίστοιχο FFmpeg καταγραφής και Chromium. Τα `ION_PLAYWRIGHT` και `ION_CHROMIUM` δέχονται εναλλακτική τοπική διαδρομή. Η εξαγωγή βίντεο χρησιμοποιεί επίσης τα `ffmpeg` και `ffprobe` του συστήματος. Το `?backup=1` εμφανίζει στη σκηνή και στο παιχνίδι την ένδειξη «ΗΧΟΓΡΑΦΗΜΕΝΟ». Τα αρχεία `data-local/backup/stage.webm` και `game.webm` περιέχουν εικόνα και ορατό κείμενο για ζωντανή αφήγηση. Η κάμερα είναι συνθετική.
